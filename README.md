# ⚔️ VocabClash — Govt Exam Vocabulary Battle Arena

**VocabClash** is a competitive, gamified edtech platform designed to help government exam aspirants (SSC CGL, CHSL, Banking IBPS/SBI PO, CDS, NDA, and State PSC) master English vocabulary through real-time 1v1 live duels, streak rewards, and targeted spaced repetition drills.

---

## ✨ Key Features

- ⚔️ **Live 1v1 Vocabulary Duels**: Fast-paced speed duels with timed multiple-choice questions, speed multiplier bonuses, and real-time opponent simulations.
- 🎯 **Targeted Exam Modes**: Curated question banks tailored for:
  - **SSC (CGL, CHSL, CPO, MTS)**
  - **Banking & Insurance (IBPS PO/Clerk, SBI)**
  - **Defense & Civil Services (NDA, CDS, AFCAT)**
  - **Grammar & Vocab Categories**: Synonyms, Antonyms, One-Word Substitutions, Idioms & Phrases, and Spelling errors.
- 📕 **Mistake Vault & Spaced Repetition**: Automatically saves incorrect answers to a personalized vault for focused re-testing until mastered.
- 🔥 **Daily Streak Engine**: Real question-based streak tracking with streak milestones and daily bonus League Points (LP).
- 🏆 **Tiered Competitive Leagues**: Progress from *Bronze Aspirant* up to *Grandmaster Topper* as your LP grows.
- ☁️ **Firebase & Google 1-Tap Sync**: Cloud synchronization for rank, LP, streak history, and mistake vault across all devices.
- 👑 **VIP Pro Pass**: Integrated Razorpay payment flow for unlocking unlimited AI drills, mock exam sets, and advanced performance analytics.
- 🔊 **Haptic Audio & Responsive UI**: Immersive sound effects and full mobile-first responsive layout (installable as PWA).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Canvas-Confetti
- **State & Storage**: React Hooks, LocalStorage fallback with Firebase Firestore
- **Authentication**: Firebase Authentication (Google 1-Tap)
- **Audio**: Web Audio API Sound Synthesizer
- **Payments**: Razorpay Checkout Integration
